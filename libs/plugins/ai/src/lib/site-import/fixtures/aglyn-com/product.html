BEFORE YOU START

Questions about the all-in-one website platform.

Straight answers on what is included, what is gated by plan, and how Aglyn AI helps.

What is included in Aglyn?

The website builder, store and bookings, forms and Inbox, CRM, media library, workflows, email campaigns, popups, analytics, datasets, a plugin marketplace and Aglyn AI, all in one console on one bill.

Do I need plugins or other tools to run my website?

No. Commerce, forms, the CRM, media, workflows and email are part of the platform. Aglyn itself is built from the same products you get.

Which parts are free?

One website on an aglyn.app address with up to five pages, the Besigner builder, forms, the media library and a monthly allowance of Aglyn AI credits. Your own domain, the store and the CRM start at Starter.

Can I start with just a website and add the rest later?

Yes. Build and publish the site first; switch on the store, bookings, CRM or campaigns from your console when you need them. Nothing has to be migrated.

Is Aglyn open source?

Yes. Aglyn is Apache-2.0 and self-hostable with Docker; the hosted platform runs the same code.

Can one account run many websites?

Yes. The same console runs one site or an agency's whole portfolio, with per-site roles, shared components and one bill.

What is Aglyn?

Aglyn is a website builder with the store, forms, CRM, email, analytics and Aglyn AI built in. It is open source and free to start.
