# @aglyn/plugins-domains

Domains feature plugin. Scaffolded by `tools/scripts/create-plugin.mjs`
(AGL-425); see `apps/docs/docs/developers/plugins/building-feature-plugins.md` for
every extension surface and the loading model.

- Surfaces: console, consoleApi
- Loaded per workspace via `org.enabledPlugins` ('domains') and the
  generated loader manifests (`plugins.config.json`).
