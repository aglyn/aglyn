# Site Protection & Error Pages

Control who can see your pages and what visitors see when something's not available.

:::info Plan availability
Included on **every plan**. Per-page visibility, page passwords, custom error pages and
maintenance mode are not tier-gated.
:::

## Where these controls live

The three features on this page are set in two different places, and neither is the pages
list:

| What you want | Where it is |
| --- | --- |
| A page's **visibility** (public, unlisted, password, members-only) and its **page password** | The **Page Access** card on that page's detail view |
| **Error pages** for 404 / 401 / 403 / 503 | The **Error pages** section of the site's **Admin** area |
| **Maintenance mode** | The same **Error pages** section, in **Admin** |

A page's own visibility is set by anyone who can edit that page. The **Error pages**
section is different: both settings there are site-wide — maintenance mode replaces every
page for every visitor — so, like deleting the site, they live in **Admin** and are
limited to **site admins**.

![The Page Access card on a page's detail view, with the Visibility menu open on Public, Unlisted, Password protected and Members only](/img/seo/page-access-visibility.png)

## Per-page passwords {#per-screen-passwords}

Protect individual pages with a **password**, so only people with the code can view them.
You can also set a custom **not-found** page for missing addresses.

## Custom error pages {#custom-error-screens}

Design your own **404 / 401 / 403 / 503** pages in the Besigner, so they match your brand
instead of showing a generic message.

## Maintenance mode

Flip your site into **maintenance mode** to show a designed 503 while you work, then switch
it back when you're ready.
