# Screens & Layouts

Screens are your pages. Layouts are the shared frames those pages render inside. Reusable
components are the repeatable pieces you drop into either. Templates are saved starting
points you can build from. Each one has its own page — start with the question you have.

## Which one do you want?

| You want to… | Go to |
| --- | --- |
| Add a page, change its URL, or check your screen allowance | [Screens](screens.md) |
| Put a header, nav or footer around many pages at once | [Layouts](layouts.md) |
| Build a card or block once and repeat it | [Reusable components](../besigner/reusable-components.md) |
| Start from a saved page, layout or whole site | [Your templates library](../site-templates/templates-library.md) |
| Publish, roll back, or schedule a version | [Versions & scheduled publishing](versions-and-publishing.md) |

:::info Plan availability
**Free** for core screens and layouts. Higher tiers raise caps on screens, versions, and
reusable components.
:::
