# Pages & Layouts

Pages are what your visitors see at each address. Layouts are the shared frames those pages
render inside. Reusable components are the repeatable pieces you drop into either. Templates
are saved starting points you can build from. Each one has its own guide — start with the
question you have.

## Which one do you want?

| You want to… | Go to |
| --- | --- |
| Add a page, change its URL, or check your page allowance | [Pages](screens.md) |
| Put a header, nav or footer around many pages at once | [Layouts](layouts.md) |
| Build a card or block once and repeat it | [Reusable components](../besigner/reusable-components.md) |
| Start from a saved page, layout or whole site | [Your templates library](../site-templates/templates-library.md) |
| Publish, roll back, or schedule a version | [Versions & scheduled publishing](versions-and-publishing.md) |

:::info Plan availability
**Free** for core pages and layouts. Higher tiers raise caps on pages, versions, and
reusable components.
:::
